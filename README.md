Future Self Feedback System
1. プロジェクト概要
「未来の自分」からコーチングを受け、目標達成を加速させるためのAIフィードバックアプリです。
単なるタスク管理ではなく、目標に対する「達成確率」や「評価項目」を可視化し、日々の進捗をAIが客観的に査定・助言を行うことで長期的な目標達成をサポートします。

2. 特徴
 未来の自分によるフィードバック: 日々の進捗を報告すると、AIが「未来の自分」の視点から具体的かつ励みになるアドバイスを生成。

 進捗の定量化: フィードバック内容から、達成確率（0-100%）と5つのスキル項目を抽出し、グラフとして可視化。

 継続支援: 目標ごとのメッセージ履歴を保存し、挫折しがちな長期目標のプロセスを記録。

3. 使用技術スタック
サーバーレス構成による軽量・高効率な設計を採用しています。

 Frontend: React / Tailwind CSS

 Backend: AWS Lambda (Python)

 Database: Amazon DynamoDB

 AI Model: Amazon Bedrock (Anthropic Claude 4.5 Haiku)

4. 開発の記録・想い
本プロジェクトは、単にアプリを動かすこと以上に、「1から設計し、手を動かす過程」を大切にしました。

AI（Claude）は強力なパートナーでしたが、アーキテクチャの設計、DBのデータ構造の策定、エラーハンドリングのロジック構築など、すべての意思決定は自分自身で行いました。

苦労した点: 最初はデータの保持と通信、そしてJSON変換エラーなどのサーバーサイド特有の課題に直面しました。しかし、デバッグを繰り返す中で「なぜデータが保存されないのか」「なぜ型が一致しないのか」を一つずつ突き止め、解決していくプロセスこそが、この開発における最大の学びでした。

開発の本質: コードを書くこと以上に、問題に対して「どう解決するか」を考え抜く力が身につきました。これはどんな開発環境になっても変わらない、エンジニアとしての根幹になる経験だったと感じています。

5. 今後の運用・展望
一旦「完成」としましたが、エンジニアリングに終わりはありません。今後は以下の運用改善を計画しています。

UXの磨き込み: チャットUIの更なるレスポンス向上。

データ分析の強化: 過去の履歴から、自分の成長傾向をさらに細かくグラフ化する機能。

運用の安定化: 長期的なデータ蓄積に向けたバックアップ体制の最適化。
